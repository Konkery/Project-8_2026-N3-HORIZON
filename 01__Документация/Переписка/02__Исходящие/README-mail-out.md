# README-mail · 02__Исходящие

Здесь создаются и хранятся официальные письма исполнителя (ООО «Горизонт»).

- Драфты содержательной части — в подкаталоге `00__draft\`, формат по умолчанию
  **markdown** (суффикс `…-draft.md`), если пользователь явно не указал иное;
- выпуск на официальном бланке, присвоение номера, ФИО и подпись — пользователем;
  выпущенный экземпляр — в корень этого каталога;
- во всех письмах — строка `Тема письма:` (в markdown-драфте — сразу под блоком
  реквизитов); значение темы переносится в реестр дословно, по ней письмо
  ищется в переписке.
