## 4. КРАТКИЕ КОММЕНТАРИИ ПО ПУНКТАМ РЕЕСТРА

- **Приём экземпляра (п. 2)** — оформляется актом по форме М15 в `01__Документация\` заказа (строка появится одновременно в реестре docs).
- **Габариты и масса** — берутся из ИД производителя и КД (`03__Проект\01__ИД\`, `77__Контрагенты\`); при изменении КД — перевыпуск версии с датой.
- **Стоимость перевозки** — после факта переносится строкой в реестр затрат заказа ([README-costs.md](../06__Затраты/README-costs.md)).

## 5. ПОРЯДОК ВЕДЕНИЯ

1. Строка п. 3 заводится в день передачи груза перевозчику, закрывается по получении.
2. Указываются: перевозчик, отправитель/получатель, номер отправки, доверенность, стоимость перевозки и страховки.
3. Маркировка — версия схемы в `02__Маркировка\` с датой; требования — реестр docs.
